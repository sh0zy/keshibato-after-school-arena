# T字レバー コントローラー

消しバト！を「引っぱって、はなす」の2動作だけで遊ぶための自作コントローラーです。
レバーを引いた距離が発射の強さになり、手を離した瞬間に発射されます。ボタンはありません。

- ファームウェア： [`t-lever/t-lever.ino`](t-lever/t-lever.ino)（ESP32 / Arduino）
- アプリ側の処理： [`../src/game/lever.ts`](../src/game/lever.ts)、画面は [`../src/components/Lever.tsx`](../src/components/Lever.tsx)

## 部品

| 部品 | 数 | 仕様のめやす |
| --- | --- | --- |
| ESP32 開発ボード | 1 | ESP32-C3 / ESP32-S3 / 無印 ESP32 のいずれでも可 |
| スライドボリューム | 1 | 10kΩ・**Bカーブ（リニア）**・ストローク 60〜100mm |
| φ8mm 金属シャフト | 1 | 長さはストローク＋100mm 程度 |
| リニアベアリング LM8UU | 2 | シャフトを支え、ボリュームに横方向の力をかけないため |
| 圧縮バネ | 1 | シャフトに通る内径のもの |
| 0.1µF セラミックコンデンサ | 1 | ADC のノイズ取り（省略可だが、入れると値が安定する） |
| T字グリップ・ケース・ストッパー | 各1〜2 | 3Dプリント |
| M3 ネジ類 | 適量 | |
| USB ケーブル | 1 | **データ通信対応のもの**（充電専用ケーブルでは動きません） |

## 配線

```
スライドボリューム
  1番（端）   ──────── GND
  2番（中点） ──┬───── SENSOR_PIN（ADC）
                └─ 0.1µF ─ GND
  3番（端）   ──────── 3V3
```

`SENSOR_PIN` はボードごとにファームウェア側で切り替わります。

| ボード | ピン | 備考 |
| --- | --- | --- |
| ESP32-C3 / C6 | GPIO3 | |
| ESP32-S2 / S3 | GPIO4 | |
| 無印 ESP32 | GPIO34 | ADC2（GPIO0,2,4,12〜15,25〜27）は Wi-Fi と衝突するため使わない |

> **5V は絶対に 3V3 の代わりに使わないでください。** ESP32 の ADC は 3.3V までです。

機構で大事なのは、**シャフトの荷重をリニアベアリングで受け、スライドボリュームには位置を測る仕事だけをさせる**ことです。T字グリップを両手で引くと横方向の力もかかるため、ボリュームのツマミで荷重を受けると早く壊れます。

引く向きが逆（引くと値が下がる）配線でもかまいません。アプリ側のキャリブレーションがそのまま吸収します。

## 書き込み

Arduino IDE に「esp32 by Espressif Systems」のボードパッケージを入れてから：

1. `t-lever/t-lever.ino` を開く
2. ツール → ボード で使っているボードを選ぶ
3. ESP32-C3 / S3 などの USB CDC 搭載ボードでは、ツール → **USB CDC On Boot: Enabled**
4. 書き込む
5. シリアルモニタ（115200 baud）を開くと、`V 1234` のような行が毎秒100件流れます

arduino-cli を使う場合（無印 ESP32 の例）:

```bash
arduino-cli core install esp32:esp32
arduino-cli compile --fqbn esp32:esp32:esp32 firmware/t-lever
arduino-cli upload --fqbn esp32:esp32:esp32 -p COM5 firmware/t-lever
```

## アプリとつなぐ

1. **パソコンの Chrome か Edge** でアプリを開く（Web Serial API を使うため、Safari・Firefox・スマートフォンでは使えません）
2. 対戦をはじめて、画面下の **「T字レバー」** を押す
3. **「レバーをつなぐ」** → ポート選択で ESP32 を選ぶ
4. 引き幅をあわせる（**最初の一度だけ。設定は端末に保存されます**）
   1. レバーから手を離した状態で **「手を離した位置を 0% にする」**
   2. いちばん奥まで引いた状態で **「いちばん奥まで引いて 100% にする」**
5. 以降は、レバーを引くとパワーが動き、手を離すと発射します

ポートは一度許可すれば記憶されるので、次回以降は対戦画面を開いた時点で自動的につながります。

### 狙う向き

レバーは強さと発射だけを受け持ちます。向きは矢印キー（←→）または「角度・打点・パーツの能力」の **狙う角度** で合わせてください。

## 通信の約束

ESP32 → アプリ（改行区切り、115200 baud）

| 行 | 意味 |
| --- | --- |
| `# keshibato t-lever v1 pin=34 adc=4095 rate=100hz` | 起動時の自己紹介。アプリは `#` で始まる行を読み飛ばす |
| `V 1234` | ADC の生の値（0〜4095）。アプリが使うのはこれだけ |

アプリ → ESP32

| 行 | 意味 |
| --- | --- |
| `?` | 自己紹介をもう一度送る |

強さへの変換・平滑化・発射判定はすべてアプリ側（`src/game/lever.ts`）にあります。感触を変えたいときは、そこの定数（`ENGAGE` / `DROP` / `RETURN_SPEED` / `MIN_FIRE` / `SMOOTH`）を調整してください。ファームウェアの書き直しは不要です。

## うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| ポート選択に出てこない | データ通信対応の USB ケーブルか。C3/S3 なら `USB CDC On Boot: Enabled` か。無印 ESP32 なら CP2102 / CH340 のドライバが入っているか |
| 「ポートを開けませんでした」 | Arduino IDE のシリアルモニタなど、他のアプリがポートを使っていないか |
| 値が届かない（受信待ちのまま） | シリアルモニタで `V ...` が流れているか。ボーレートが 115200 か |
| 「0%と100%の差が小さすぎます」 | 中点が SENSOR_PIN につながっているか。両端が GND と 3V3 か。ボリュームがBカーブ（リニア）か |
| 引いていないのに値が揺れる | 0.1µF を中点と GND の間に入れる。配線を短くする。無印 ESP32 では ADC1（GPIO32〜39）を使う |
| 勝手に発射される | ストッパーでレバーが完全に戻りきるか確認する。それでも出るならキャリブレーションをやり直す |
| 発射が重い／軽すぎる | 引き幅の登録をやり直す。それでも合わなければ `src/game/lever.ts` の `MIN_FIRE` と `DROP` を調整する |
